## Where they go
Creator Dashboard, Creations, SUPERNATURALS, Places, the start place: **Icon** takes
`icon_512.png` and **Thumbnails** takes the 1920 x 1080 images. The first thumbnail is the one
most players see, so lead with `thumbnail_1_hall_titled.jpg` (or the Halloween one during
launch week). The clips are for TikTok, YouTube Shorts, X and Discord, and for Roblox ads if you
run them.

## Please read before uploading
- These are stylised key art, not in-game screenshots. They show the game's own world (the Hall
  of the Eight, the Lantern, the statues, the Lounge and the Archive), but the real game is built
  from Roblox parts. Roblox asks that thumbnails represent the experience, so add real
  screenshots captured in Studio once the hall and statues are finished, and never promise
  something the game doesn't have.
- Use the Halloween images and clip only if the Halloween decorations are live in the game.
- About 0.9 of the account's 10 free Higgsfield credits are left.
